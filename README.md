# HexMarble

**公開URL: https://matsumitsu.github.io/HexMarble/**

六角形のグリッドにタイルを並べてマーブルのコースを組み立て、スタートからマーブルを転がしてゴールまで届くか試す、Webブラウザ向けの3Dサンドボックスゲームです。

- TypeScript + Vite + Three.js（UIは素のDOM、外部アセットなし）
- 物理エンジンは使っていません。マーブルは各タイルに定義した経路に沿って動き、速度は「高低差による加速」と「一定の減衰」だけで決まります。固定タイムステップで計算するため、同じコースなら毎回同じ結果になります。

## 起動方法

Node.js 20 以上が必要です。

```bash
npm install
npm run dev       # 開発サーバー（http://localhost:5173/HexMarble/）
npm test          # 単体テスト（Vitest）
npm run build     # 型チェック + 本番ビルド（dist/）
npm run preview   # ビルド結果の確認
```

`main` ブランチへ push すると、GitHub Actions が「依存関係のインストール → 単体テスト → ビルド → GitHub Pages へデプロイ」の順に実行します。テストが失敗した場合はデプロイしません（`.github/workflows/deploy.yml`）。

## 遊び方

編集モードでも、スタートからマーブルが常に発射されます。ゴールしても失敗しても、少し待ってから自動で再発射されるので、コースを組みながら結果を確かめられます。コースを変更すると、その場で発射し直します。分岐の切り替え状態は再発射のあいだ引き継がれるので、発射のたびに出口が交互に変わります。ゴールに入ると、ゴールタイルから小さな花火が上がります。

| 操作 | 内容 |
| --- | --- |
| パレット / `1`〜`9` | タイルを選んで設置モードにする。グリッドをクリックすると、そのセルの一番上に置く |
| `Q` | 設置モードでは設置モードを終了する。それ以外では、カーソル下のタイルを種類・向き・レベルごと拾って設置モードにする（スポイト） |
| `R` / `Shift+R` | 設置モードでは置く前のタイルを、それ以外ではカーソル下のタイル（なければ選択中のタイル）を60°回転 |
| 右クリック長押し | カーソル下のタイルを削除 |
| `Esc` | 選択ツールに戻る（クリックで置いたタイルを選択） |
| `E` / `Shift+E` | 設置モードでは置くレベルを上げる / 下げる（足りない分の支柱は置くときに自動で積む）。それ以外では、カーソル下のタイル（なければ選択中のタイル）のレベルを上げる / 下げる（真下に支柱を差し込む / 外す） |
| `PageUp` `]` / `PageDown` `[` | 選択中のタイルの高さを上げる / 下げる |
| `Delete` | 選択中のタイルを削除 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Tab` | 編集モード / 実行モードの切り替え |
| `Space` | 実行モードで再生 / 一時停止 |
| `W` `A` `S` `D` | カメラを前後左右に移動 |
| マウス | 左ドラッグで回転、右ドラッグでパン、ホイールでズーム |

実行モードでは、一時停止、発射し直し（リセット）、再生速度の変更ができます。

- タイルを選ぶと、置けるセルが青、既存のコースとつながるセルが緑でハイライトされます。
- 編集モードでは、つながっていない接続口にオレンジの印が付きます。
- コースは「保存 / 読込」でブラウザ（localStorage）に、「JSON書き出し / JSON読み込み」でファイルに保存できます。

### タイル

| タイル | 説明 |
| --- | --- |
| スタート | マーブルの発射台。初速を持たせて送り出す（1つだけ） |
| 直線 | 向かい合う辺どうしをつなぐ |
| カーブ60° / カーブ120° | 進行方向を60° / 120° 変える |
| 坂 | 1レベル下る（2レベル分の高さを占める） |
| 支柱 | 高さを1レベル上げる土台。重ねて置ける |
| 分岐 | 通るたびに出口を交互に切り替える。逆向きに通すと合流になる |
| 落下口 | マーブルを真下のタイル（上面に接続口を持つ分岐・落下口・ゴール）へ落とす |
| ゴール | どの辺からでも、上からでもマーブルを受け止める |

## 仕組み

```
src/
  core/            描画に依存しないロジック（単体テスト対象）
    hex.ts           アキシャル座標(q, r)、隣接方向、回転
    parts.ts         タイル定義（接続口・経路データ）
    course.ts        コースのデータとイミュータブルな編集操作
    connections.ts   接続判定
    simulation.ts    経路に沿ったマーブルの運動計算
    launcher.ts      ゴール・失敗後の自動再発射
    history.ts       Undo / Redo（スナップショット方式）
    serialize.ts     JSON 保存形式と検証
  render/          Three.js による描画（ジオメトリはすべてコード生成）
  ui/              素の DOM の UI
  app.ts           入力・モード・描画ループをまとめるコントローラ
tests/             Vitest の単体テスト
```

- **グリッド**: 尖頂型の六角形をアキシャル座標 (q, r) で扱います。辺 `i`（0〜5）は東から反時計回りに60°ずつ。各タイルは設置レベル（0〜8）を持ち、同じセルに積み上げられます。
- **接続判定**: 接続口は「位置（辺0〜5 / `up` / `down`）」と「タイルの設置レベルからの相対高さ `h`」で定義します。辺の接続口は隣のセルの向かい合う辺に、`down` は同じセルの真下のタイルの `up` に、絶対レベル（設置レベル + `h`）が一致するときだけつながります。
- **運動計算**: 経路点列から弧長テーブル付きの折れ線を作り、`dv/dt = -g·(dy/ds) - 減衰` を固定ステップで積分します。経路の終端で接続先の経路へ乗り継ぎ、接続先がなければ放物線を描いて落下（失敗）、速度が0以下になれば停止（失敗）します。物理定数は `src/core/constants.ts` の `DEFAULT_PHYSICS` にあります。

## タイルの追加手順

例として、新しいタイル `bumper` を追加する場合の手順です。

1. **種類を追加する** — `src/core/parts.ts` の `PartType` に `'bumper'` を加えます。
2. **定義を書く** — 同じファイルの `PARTS` に `PartDef` を追加します。
   - `ports`: 接続口の一覧。`{ id: 辺番号 0〜5 | 'up' | 'down', h: 相対高さ }`
   - `routes`: 入口から出口までの経路。`{ from, to, points }`。`points` は回転前のローカル座標で、マーブルの中心が通る点列です（`y` はタイル底面からの高さ）。端点は接続口の位置（`portLocalPosition`）と一致させます。辺どうしなら `edgeToEdge(a, b)` と `twoWay(a, b, pts)` が使えます。
   - 同じ `from` の経路を複数書くと、通るたびに交互に選ばれます（分岐）。
   - `span`（占有する高さ）、`color`、`name`、`description` も設定します。
3. **パレットに並べる** — `PALETTE_ORDER` に追加します（先頭9個は数字キーで選べます）。アイコンは経路データから自動生成されます。
4. **見た目を作る** — `src/render/meshes.ts` の `BUILDERS` に、ローカル座標（底面 y = 0、辺0が +X 方向）でメッシュを作る関数を追加します。`basePlate` を呼べば、厚みのある土台の板に、経路データに沿ったハーフパイプの溝が自動でくり抜かれます（溝の形は `src/render/tileSurface.ts` の `surfaceHeight` で計算）。
5. **テストする** — `npm test` を実行します。「経路の端点は接続口の位置と一致する」テストが定義の誤りを検出します。必要に応じて `tests/simulation.test.ts` に、そのタイルを通るコースのテストを追加してください。
